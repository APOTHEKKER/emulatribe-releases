# PORK Emulatribe 2 – Downloads

Hier liegen nur die Dateien, die das Setup herunterlädt – kein Quellcode.

| Ort | Inhalt |
| --- | --- |
| `version.txt` | neueste Version (`v1.26.106`), ohne Zeilenumbruch |
| `changelogs/` | ein Changelog pro Release, Name `TT.MM.JJJJ.txt` |
| `languages/` | Sprachdateien des Setups (`de`, `es`, `fr`, `ru`) |
| Release `v<Version>` | `v<Version>.zip` mit App und Setup |
| Release `assets` | KORG-Treiber, Schriften, WebView2-Pakete und -Installer |

Veröffentlicht wird mit `npm run release` im Projekt (erst das Release, dann der Changelog, zuletzt `version.txt`).
